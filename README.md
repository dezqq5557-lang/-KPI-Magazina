# KPI Магазина — рабочая основа v1

Это desktop/web-приложение-основа для аналитики магазина.

Запуск:
1. Установить Python 3.11+.
2. В терминале открыть папку проекта.
3. Выполнить: `python app.py`
4. Открыть в браузере: `http://127.0.0.1:8000`

Сейчас реализовано:
- локальная SQLite база;
- продажи, сотрудники, товары и категории;
- импорт CSV;
- автоматический расчёт выручки, чеков и среднего чека;
- API-адаптер Контур.ОФД подготовлен как отдельный модуль;
- настройки API хранятся локально и не выводятся в интерфейс.

ВАЖНО:
Для реального подключения к Контур.ОФД потребуется официальный API-доступ/ключ интегратора. Секреты в код проекта не зашиваются.

Формат CSV для импорта:
date,time,amount,employee,category,product,quantity,cost,type
2026-10-07,12:15,125.50,Анна,Одежда,Футболка,1,55.00,sale

type: sale или refund.
