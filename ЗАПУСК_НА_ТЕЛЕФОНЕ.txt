KPI МАГАЗИНА — запуск на телефоне

1. На компьютере установите Python 3.11 или новее.
2. Откройте папку проекта в терминале и выполните:
   pip install -r requirements.txt
   python app.py
3. Узнайте локальный IPv4-адрес компьютера:
   Windows: откройте CMD и выполните ipconfig, найдите «IPv4-адрес» активного Wi-Fi адаптера (например, 192.168.1.25).
4. Подключите телефон к той же сети Wi-Fi и откройте в браузере:
   http://АДРЕС-КОМПЬЮТЕРА:8000
   Например: http://192.168.1.25:8000
5. Для удобства:
   iPhone (Safari): Поделиться → На экран «Домой» → Добавить.
   Android (Chrome): меню ⋮ → Добавить на главный экран / Установить приложение.

Важно:
- Компьютер должен оставаться включённым, а приложение — запущенным.
- Телефон и компьютер должны быть в одной сети Wi-Fi.
- Если Windows спросит о доступе для Python, разрешите доступ в частных сетях.
- Не открывайте порт 8000 в интернет и не используйте публичный Wi-Fi: в текущей версии нет авторизации пользователей и HTTPS.
- Для доступа из любой точки мира потребуется отдельно настроить безопасный сервер, HTTPS и вход по паролю.
